GraphContext MCP: Pre-Computed Knowledge Graphs for Token-Efficient AI Context Retrieval

Michele Meattini

Preprint  ·  2025

Abstract

AI agents that need cross-source context (e.g., a CRM deal in Notion and an email thread in Gmail) currently suffer from three problems: high latency due to sequential API calls, token bloat from dumping full documents into the context window, and semantic blind spots where cross-source entity links are invisible to any single data source.

We present GraphContext, a three-layer system that decouples context ingestion from context serving. An offline entity extraction engine parses disparate data sources, runs named entity recognition (NER) and entity resolution, and persists the results in a unified knowledge graph. A generic, source-agnostic Model Context Protocol (MCP) server then serves surgical subgraphs in <1 ms with 98.3% fewer tokens than the raw-API baseline.

We formalize a cost model proving that the break-even point — the number of queries after which pre-computation amortizes its ingestion cost — is typically Q* = 2 for a 50-document corpus using a sub-cent-per-million-token LLM. Experimental results over 100 iterations show an 8.6× latency reduction and a 57.7× token reduction compared to the traditional live-API approach, while preserving answer relevance.

Automatic Classification of Egyptian Hieroglyphs via Deep Learning

Michele Meattini

BSc Thesis  ·  Università degli Studi di Firenze  ·  2025

Abstract

This work addresses the problem of automated classification of Egyptian hieroglyphs using deep learning techniques. Starting from the construction of a dedicated dataset, the project comprised preprocessing and data augmentation phases designed to improve model robustness against class imbalance and within-class visual variation.

A ResNet50 architecture with transfer learning was adopted and trained through advanced optimisation strategies to improve efficiency and generalisation capacity. A dedicated inference interface was also developed to make the model accessible in applied and experimental settings.

The work demonstrates that deep learning can be effectively applied to unconventional domains — such as the study of ancient scripts — contributing to the computational analysis and valorisation of cultural heritage.

About

My interests sit at the intersection of knowledge representation, neural networks, and efficient AI system design. I am drawn to problems where data is scarce, noisy, or structurally heterogeneous — domains where standard pipelines underfit and problem-specific architecture choices matter.

Outside research, I work as Project Manager at overMedia Srl and build side projects at the edge of software and hardware — from IoT smart-home systems to generative web tools.
