# michelemeattini.github.io

Personal research and project site for Michele Meattini.

Built with plain HTML/CSS — no framework, no build step.

## Deploy to GitHub Pages

1. Create a repo named `michelemeattini.github.io` on GitHub
2. Push the contents of this folder to the `main` branch
3. Go to Settings → Pages → set Source to `main`, folder `/` (root)
4. Your site will be live at https://michelemeattini.github.io/

## Adding a paper / article

Drop the PDF in the root folder (or a `papers/` subfolder) and add a new `<article class="paper-card">` block in `index.html` inside `<section id="research">`.

## Adding a writing post

Create a new `.html` file (e.g. `posts/hieroglyphs-notes.html`) and link to it from the Writing section in `index.html`.
